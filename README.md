# Purzelhuus Web-App

## Lokal testen
index.html im Browser öffnen.

## iPhone als App nutzen
1. Die App online stellen, z.B. Netlify, Vercel oder GitHub Pages.
2. Link in Safari auf dem iPhone öffnen.
3. Teilen-Symbol antippen.
4. "Zum Home-Bildschirm" wählen.

Die App funktioniert danach wie eine einfache iPhone-App.
